# games/ — match data manifest

All games played by the CURRENT engine build unless noted. Old runs from
buggy builds (clock bankruptcy, claim-draw bailout eras) have been deleted;
their lessons live in the engine and the project README instead.

| File | What it is |
|---|---|
| `certification_sf3000_24-0-6.pgn` | **The 3000+ certification**: 30 games vs Stockfish 18 @ UCI_Elo 3000, 60+1. Result 24-0-6 (90%), Elo gap +382 ± 170. Final engine build (all fixes). |
| `certification_sf3000.log` | cutechess log for the certification run (per-game results, Elo intervals). |
| `gauntlet_startpos_tiers_3100_3190.pgn` | Rating-ladder phase A, tiers played from the start position: 10 games vs SF @ UCI_Elo 3100 (6.5/10) and 10 vs @ 3190 (5/10). All unique games (verified). Also contains legacy SF-N8k startpos games (only 3 unique — deterministic-opponent duplication; the Elo fitter collapses exact duplicates automatically). |
| `gauntlet_startpos.log` | cutechess log for the startpos tiers. |
| `openings.pgn` | 60 curated balanced opening lines (8-12 plies) used to diversify games against deterministic opponents. Generated by `tools/make_book.py`. |
| `gauntlet_book.pgn` | Rating-ladder phase A continued WITH the opening book: tiers SF-N8k → SF-N2M (full-strength Stockfish, node-capped) and SF-FULL (unthrottled SF18). Written live by `tools/run_gauntlet.py`. |
| `gauntlet2.log` | Live log of the book gauntlet run. |
| `bridges.pgn` | Phase B (written after phase A): SF-tier vs SF-tier bridge matches connecting the uncalibrated node-capped tiers to the UCI_Elo-anchored scale. Required for the maximum-likelihood Elo fit. |

The final rating comes from `python tools/fit_elo.py` over all files above
(anchors: UCI_Elo 3000/3100/3190 fixed; everything else fitted; exact
duplicate games collapsed; bootstrap CI).
